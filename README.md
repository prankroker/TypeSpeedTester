# TypeSpeed Tester

A sleek, responsive typing speed test app that measures your WPM and accuracy in real-time.

---

## ✨ Features

- **Real-time WPM tracking** - See your speed update as you type
- **Accuracy measurement** - Know exactly how precise your typing is
- **Instant restart** - Jump right back in with a single click
